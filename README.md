# Афіша подій міста (city-events)

Навчальний проєкт з дисципліни «Програмування веб-застосувань», варіант 5.

Клієнтський застосунок для перегляду культурних подій міста.

## Заплановані розділи сторінки
- шапка з назвою і навігацією;
- блок фільтра за датою/категорією;
- список подій (картки);
- блок деталей обраної події;
- підвал.

## Структура проєкту
```
city-events/
├── index.html
├── css/style.css
├── js/app.js
├── assets/img/
├── .gitignore
└── README.md
```

## Запуск
Відкрити `index.html` через розширення Live Server у VS Code.
